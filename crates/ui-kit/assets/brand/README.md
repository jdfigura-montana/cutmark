Files per app (`{app}` = audio, recorder, video, prompter):
- `mark-{app}.svg`, `mark-{app}-light.svg`: the Splice mark, 64 grid, for dark and light surfaces.
- `icon-{app}.svg`: 256 app icon tile. `icon-{app}.ico`: 16, 20, 24, 32, 40, 48, 64, 256 px.
- `wordmark-{app}.svg`, `wordmark-{app}-light.svg`: mark plus "CutMark" plus the app name, text outlined (no font needed). Height 100 units; scale by height.

If the ui-kit accent presets differ from the hex values above, regenerate rather than hand-edit.
