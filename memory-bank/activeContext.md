## Key learnings
- cpal 0.18.2 is an API rewrite vs 0.15: SampleRate/FrameCount are plain u32/u16 aliases (no tuple struct); supported_output_configs() yields SupportedStreamConfigRange with contains_rate/try_with_sample_rate; build_output_stream takes StreamConfig BY VALUE plus (data_cb, err_cb, Option<Duration>); Device::name() gone â€” use device.description().name() (Display / to_string() PANICS when description() fails; engine.rs and input.rs both use description().name() since 11.1b); SampleRate(project_rate) is invalid syntax.

The warning is just "Tried to (de)allocate memory in a thread that forbids allocator calls!" on stderr: no size, no call site, and violation_count() is per-thread (the audio thread's, not readable from the UI/test thread).
