# Audio Editor 1.3 Spec: Stream Deck

Builds on docs/suite/Remote-Control.md (protocol, crate, plugin shell) and the S1 phase 14c shortcut table (`apps/audio-editor/src/shortcuts.rs`). Release: audio editor 1.3.0, plugin 1.0.0.0.

## App side

- Start the `cutmark-remote` server at launch (if enabled in Preferences > Remote control).
- Every shortcut table id is a valid remote command and runs the same action with the same guards.
- Remote-only commands:

| Id | Args | Action |
| --- | --- | --- |
| `track.mute` / `track.solo` / `track.arm` | `track` (1-based) | Toggle that track's Mute / Solo / Record arm |
| `track.volume.step` | `track`, `ticks` (signed int) | Change track volume by 0.5 dB per tick, clamped to the track control's range |
| `zoom.step` | `ticks` | Zoom in/out, same step as + / - |
| `zoom.fit` | none | Zoom to fit (if the app has it; else zoom to project) |
| `jog.step` | `ticks`, `size` ("fine" or "coarse") | Move playhead 10 ms (fine) or 1 s (coarse) per tick; snaps if Snap is on; ignored while recording |
| `marker.step` | `ticks` | Previous / next marker by sign |

- Dial gestures and undo: track volume turns use the same undo behavior as dragging the track's volume control (one undo step per gesture). A gesture ends 500 ms after the last tick.
- A track number that does not exist returns `bad_args`.

### State published

```
{
  "project": "My Podcast" | null,
  "transport": "stopped" | "playing" | "paused" | "recording",
  "playhead_ms": 12345,
  "can_record": true,          // at least one track armed and record allowed
  "can_undo": true, "can_redo": false,
  "ripple": true, "snap": false,
  "zoom_label": "10 s",        // same text as the zoom readout
  "tracks": [ { "n": 1, "name": "Host", "mute": false, "solo": false, "arm": true, "volume_db": -3.0 } ]
}
```

- `playhead_ms` is sent at most 10 times per second while playing.

## Plugin actions (category "Cutmark Audio")

### Keys

| Action | Press | Key shows |
| --- | --- | --- |
| Play / Stop | `play_pause` | Play icon, Stop icon while playing |
| Pause | `pause` | |
| Record | `record` | Red when recording; dimmed when `can_record` is false |
| Go to start / Go to end | `jump_start` / `jump_end` | |
| Add marker | `add_marker` | |
| Previous / Next marker | `prev_marker` / `next_marker` | |
| Undo / Redo | `undo` / `redo` | Dimmed when not available |
| Split at playhead | `split_at_playhead` | |
| Ripple / Snap | `toggle_ripple` / `toggle_snap` | On state in accent blue |
| Save | `save` | |
| Track Mute / Solo / Arm | `track.*` with the track setting | Title is the track name; on state lit (Solo yellow, Mute accent, Arm red per Design Language) |
| Audio command | any id from the `welcome` command list | Title is the command label |

- Shortcut ids above are placeholders; use the real ids from `shortcuts.rs`.
- Track keys and dials have a "Track" setting (number, 1 to 64) in the property inspector.
- "Audio command" has a dropdown filled from the `welcome` command list (falls back to "Open the audio editor to load commands" when not connected).

### Dials (Stream Deck+)

| Action | Rotate | Press | Touch tap | Touch strip (layout) |
| --- | --- | --- | --- | --- |
| Zoom | `zoom.step` | `zoom.fit` | none | `$B1`: "Zoom", `zoom_label`, bar |
| Jog | `jog.step` | toggle fine/coarse | `play_pause` | `$A1`: playhead timecode, "Fine" or "Coarse" |
| Track volume | `track.volume.step` | `track.mute` | none | `$B1`: track name, dB value, bar; dimmed when muted |
| Markers | `marker.step` | `add_marker` | none | `$A1`: "Markers", playhead timecode |

- Each dial sets its trigger descriptions (rotate, push, touch) so Stream Deck shows what they do.
- Rotation ticks are coalesced in the plugin to one command per 50 ms.

## Bundled profiles

- Plugin ships two profiles the user can install on first run: "Cutmark Audio MK2" (15 keys) and "Cutmark Audio Plus" (Stream Deck+, 8 keys, 4 dials).
- MK.2 layout: row 1 Go to start, Play/Stop, Pause, Record, Go to end; row 2 Prev marker, Add marker, Next marker, Split, Save; row 3 Undo, Redo, Ripple, Snap, Track 1 Arm.
- Stream Deck+ layout: keys Play/Stop, Record, Add marker, Split, Undo, Redo, Ripple, Snap; dials Jog, Zoom, Track 1 volume, Markers.
- Profiles are built in the Stream Deck app and exported (not hand-written).

## Done when

- Key states follow the app within a frame or two; toggling in the app updates the keys.
- Commands blocked by guards show the Stream Deck alert and do nothing in the app.
- Closing the editor switches keys to "Open"; pressing one launches it and reconnects.
