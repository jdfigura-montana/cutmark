Bundled third-party components in CutMark Audio Editor
=======================================================

FFmpeg 9.0.2 libraries (avcodec-63.dll, avdevice-63.dll, avfilter-12.dll,
  avformat-63.dll, avutil-61.dll, swresample-7.dll, swscale-10.dll)
  Licence: GNU Lesser General Public License, version 3 or later (LGPL-3.0-or-later)
  Full texts: LGPL-3.0.txt and GPL-3.0.txt (this folder); the LGPL-3.0 text adds
  permissions on top of the GPL-3.0 text, so both are included
  These libraries are linked dynamically as separate DLL files beside the exe
  and the user may replace them. Build details and the source location are in
  FFmpeg-BUILDINFO.txt (this folder).

IBM Plex Sans (fonts: IBMPlexSans-Regular.ttf, IBMPlexSans-Medium.ttf,
  IBMPlexSans-SemiBold.ttf)
  Licence: SIL Open Font License 1.1
  Full text: LICENSE-IBMPlex.txt (this folder)

JetBrains Mono (fonts: JetBrainsMono-Regular.ttf, JetBrainsMono-Medium.ttf)
  Licence: SIL Open Font License 1.1
  Full text: OFL-JetBrainsMono.txt (this folder)

The Rust application code itself is separate from these components; this
file covers only third-party material bundled in the installer.
