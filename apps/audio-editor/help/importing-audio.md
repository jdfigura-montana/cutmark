Bring audio files into your project. The app imports WAV and MP3 files.

## Import from the menu

1. Open the **Project** menu and click **Import Media...** or press <kbd>Ctrl</kbd>+<kbd>I</kbd>.
2. Pick one or more files.
3. The files appear in the **Media** bin.

## Import by dragging

1. Drag files from Windows Explorer into the window.
2. The files appear in the bin.

## Add a file to the timeline

1. Drag a file from the bin onto a track.
2. The file becomes a clip at the drop position.

The bin shows each file's name and duration. Hover a file to see its format and sample rate. Right-click a file to **Preview**, **Rename**, **Reveal in Explorer**, or **Remove from Project**. If a file moves on disk, use **Relink...** to find it again.

> Tip: Hold <kbd>Ctrl</kbd> while you drop a file to insert it and push later clips right. Without <kbd>Ctrl</kbd>, the new clip replaces what it covers.

See [Working with clips](topic:working-with-clips).
