CutMark Audio can be controlled from an Elgato Stream Deck. The free Stream Deck plugin adds keys for the transport, markers, editing and track controls, and dials for zoom, jog and track volume on Stream Deck+.

## Install the plugin

1. Download the plugin (com.cutmark.suite.streamDeckPlugin) from the CutMark downloads page.
2. Double-click the downloaded file. Stream Deck installs it.
3. The actions appear in the Stream Deck actions list under **CutMark Audio**.

## Use a bundled profile

The plugin ships two ready-made layouts: **CutMark Audio MK2** for Stream Deck and Stream Deck MK.2, and **CutMark Audio Plus** for Stream Deck+. Stream Deck offers to install them when the plugin is installed. You can also drag any action onto a key or dial yourself.

## Turn on remote control

1. Open CutMark Audio and choose **Preferences** > **Remote control**.
2. Leave remote control on. The Stream Deck keys and dials follow the app while it runs.
3. When the app is closed, pressing a key launches it again.

> Tip: The Stream Deck keys follow CutMark Audio only while the Stream Deck app is running.
