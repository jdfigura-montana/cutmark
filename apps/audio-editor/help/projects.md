A project holds your tracks, clips, markers, and media. It is saved as a folder on disk.

## Save a project

1. Click **Save** in the Project menu or press <kbd>Ctrl</kbd>+<kbd>S</kbd>.
2. The project saves to its folder.

## Save a copy

1. Click **Save As...** in the Project menu or press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>.
2. Type a new name in **Name**.
3. Choose a **Parent folder**.
4. Click **Save**.

## Change project settings

1. Click **Project Settings...** in the Project menu.
2. Change the **Name** or the **Bit depth**.
3. Click **OK**.

## Close a project

1. Click **Close** in the Project menu.
2. If the project has unsaved changes, click **Cancel**, **Don't Save**, or **Save**.

The project folder holds **project.json**, a **media** folder for your audio, and **cache**, **autosave**, and **exports** folders. If the app closes unexpectedly, the start screen offers to **Recover autosave**.

> Tip: The title bar shows a dot next to the project name when the project has unsaved changes.

See [Getting started](topic:getting-started) for opening a project.
