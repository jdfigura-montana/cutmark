## Key learnings
- cpal 0.18.2 is an API rewrite vs 0.15: SampleRate/FrameCount are plain u32/u16 aliases (no tuple struct); supported_output_configs() yields SupportedStreamConfigRange with contains_rate/try_with_sample_rate; build_output_stream takes StreamConfig BY VALUE plus (data_cb, err_cb, Option<Duration>); Device::name() gone â€” use device.description().name() (Display / to_string() PANICS when description() fails; engine.rs and input.rs both use description().name() since 11.1b); SampleRate(project_rate) is invalid syntax.
- assert_no_alloc 1.1.2: allocator type AllocDisabler; warn_debug feature prints a warning instead of aborting (disable_release default keeps release builds untouched); only the #[global_allocator] static in main.rs is gated with #[cfg(debug_assertions)], the assert_no_alloc(...) calls are not (a plain call in release). The warning is just "Tried to (de)allocate memory in a thread that forbids allocator calls!" on stderr: no size, no call site, and violation_count() is per-thread (the audio thread's, not readable from the UI/test thread).
- app.rs Screen enum needed Editing(Box<Editor>) after Editor grew (clippy large_enum_variant); Callback::new dropped for a struct literal (clippy too_many_arguments).
- Editor tool on this machine repeatedly corrupted files via unintended insert_line (joined lines mid-token). Recovery pattern: git checkout -- <file>, then apply edits with a Python script (utf-8-sig read/write, assert count==1 per replacement). Prefer that for multi-edit changes.
- Task 5.2: `gen` is a reserved keyword in edition 2024 (renamed to `source`). Resampler pre-roll: 3 zero history frames cause a 2-frame transient at stream start (tests skip 4 samples). Keep-last-3 continuity implemented as a residual FIFO.

- LNK1104/LNK1201 (locked exe/pdb) after panicking test runs: kill stale audio_editor processes or delete target debug deps audio_editor-*.pdb/exe, then rebuild.
- egui 0.36 DragAndDrop::set_payload/payload::<T>()->Option<Arc<T>>/clear_payload (auto-cleans on Esc/release too; payload() is Some on the release frame). Response::drag_started() exists.
