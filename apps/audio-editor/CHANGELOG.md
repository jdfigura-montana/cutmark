# Changelog

## 1.2.0

A new look and a built-in Help system. No behavior changes to editing, recording or export.

- New look: the CutMark Design Language (Inter and JetBrains Mono type, new colors, panels and controls).
- Custom title bar with a menu bar.
- New start screen.
- Floating transport deck.
- Accent color and glass settings in View > Appearance.
- Help window with F1 context help.
- Keyboard shortcut sheet.
- First-run tour.
- About box with the license notices.
