# Changelog

## 1.3.0

Stream Deck support. It uses the free CutMark Stream Deck plugin, which is installed separately.

- Keys for the transport, markers, editing and track controls. Track keys show the track name and its mute, solo or arm state.
- Dials on Stream Deck+ for zoom, jog, track volume and markers.
- Bundled profiles for Stream Deck and Stream Deck MK.2, and for Stream Deck+.
- New Edit > Preferences... dialog (Ctrl+,) with a Remote control section: a Stream Deck switch, on by default, and a connection status line.

## 1.2.0

A new look and a built-in Help system. No behavior changes to editing, recording or export.

- New look: the CutMark Design Language (Inter and JetBrains Mono type, new colors, panels and controls).
- Custom title bar with a menu bar.
- New start screen.
- Floating transport deck.
- Accent color and glass settings in View > Appearance.
- Help window with F1 context help.
- Keyboard shortcut sheet.
- First-run tour.
- About box with the license notices.
